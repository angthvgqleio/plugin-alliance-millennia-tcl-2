## Overview

Plugin Alliance Millennia TCL-2 emulates the transparent, clinical precision of the Millennia Media TCL-2, a reference-quality compressor beloved for mastering and critical mixing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plugin Alliance Millennia TCL-2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Transparent Compression** | Ultra-low distortion VCA compression for transparent dynamics |
| **Sidechain** | External sidechain with HPF for bass-independent compression |
| **Mastering Grade** | Sub-0.01% THD for transparent mastering compression |
| **Dual Mode** | Independent left/right or linked stereo modes for mastering |
